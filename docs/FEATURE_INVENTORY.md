# Platform Feature Inventory

This document details every feature, module, sub-feature, interactive element, and expected behavior in the CourseIt-Style AI Learning Platform.

---

### Module 1: Authentication & User Lifecycle Management
- **Registration & Sign Up:**
  - Standard email and password registration with client and server-side validation.
  - Password strength verification (min 8 chars, mixed case, numbers).
  - Social Auth integration pathways (Google OAuth, GitHub OAuth).
- **Session & Token Management:**
  - JWT / secure session cookie handling.
  - Persistent login across tabs and reloads.
  - Logout with cache and session invalidation.
- **User Profile Management:**
  - Display name, bio, avatar selection/upload.
  - Learning preferences: daily study goal (30, 60, 90, 120 minutes).
  - Account deletion workflow with data cleanup.
  - Password change and credential update.
- **Engagement & Activity Tracking:**
  - Continuous learning streak counter (days active).
  - Daily study time accumulator (minutes per calendar day).
  - Activity log: completed lessons, quizzes passed, courses finished.

---

### Module 2: YouTube Course Generation Engine
- **Source Link Input:**
  - Intelligent input bar supporting standard watch links (`watch?v=...`), short links (`youtu.be/...`), and playlist links (`playlist?list=...`).
  - Validation check for malformed URLs, unreachable domains, or missing query parameters.
- **Metadata Ingestion:**
  - Extract video title, creator channel, published date, high-resolution thumbnail, duration in seconds.
  - Playlist decomposition into ordered child video entities.
- **Transcript Acquisition & Fallbacks:**
  - Automatic YouTube transcript extraction via timed-text captions.
  - Handling of non-captioned videos via user-uploaded transcript/text input fallback.
  - Graceful handling of private, deleted, age-gated, or geoblocked video URLs with actionable user error dialogs.
- **Quota & Plan Verification:**
  - Pre-generation verification of user's remaining monthly generation quota and max video duration limit.
  - Instant duplicate detection: if the URL has already been generated by another user, redirect instantly to the existing course without deducting generation allowance.

---

### Module 3: AI Processing Pipeline & Course Synthesis
- **Modular AI Orchestrator:**
  - Multi-provider abstraction supporting NVIDIA Nemotron (`nvidia/nemotron-4-340b-instruct`), OpenAI (`gpt-4o`, `gpt-4o-mini`), and local fallback.
  - Dynamic model selection via environment variables or admin configuration.
- **Semantic Course Structuring:**
  - Course-level synthesis: high-impact title, description, target audience, difficulty level (Beginner, Intermediate, Advanced), prerequisite knowledge.
  - Chapter and lesson breakdown: dividing hours of video into logical 10-25 minute learning units.
  - Semantic timestamp mapping: precise `startSeconds` and `endSeconds` for each lesson.
- **Lesson Content Enrichment:**
  - Executive summary and key takeaways for each lesson.
  - Key concepts, critical definitions, practical code/concept examples.
  - Interactive quiz generation (3-5 MCQs per lesson with rationale and video timestamps).
- **Streaming Lesson Availability (TTFL):**
  - First lesson is synthesized, saved, and marked `READY` so the user can begin learning immediately while background worker continues processing subsequent lessons.

---

### Module 4: Intelligent Course Structure & Curriculum View
- **Curriculum Overview:**
  - Chapter and lesson tree view with estimated study duration and video duration.
  - Overall course progress percentage bar.
  - Placement test callout banner (if uncompleted).
- **Lesson Item Statuses:**
  - `NOT_STARTED`, `IN_PROGRESS`, `COMPLETED`, `SKIPPED` (via placement test).
  - Toggle switch to re-enable/unskip skipped lessons at any time.

---

### Module 5: Diagnostic Placement Test
- **Assessment Generation:**
  - AI synthesizes 6-10 diagnostic questions testing key concepts across all course chapters.
- **Evaluation & Skill Mapping:**
  - User submits answers; engine grades accuracy per topic.
  - Identifies mastered topics (score >= 80% on topic questions).
- **Adaptive Curriculum Optimization:**
  - Flags lessons corresponding to mastered topics as `SKIPPED`.
  - Recalculates total course study duration and daily study schedule.
  - User can review diagnostic score summary, retake test, or restore all lessons.

---

### Module 6: Distraction-Free Video Learning Experience
- **Interactive YouTube IFrame Player:**
  - Fully integrated YouTube IFrame Player API.
  - Real-time video time tracking and state synchronization (play, pause, seek, buffer).
  - Auto-play toggle, playback rate controls (1x, 1.25x, 1.5x, 2x).
- **Lesson Progression & Navigation:**
  - "Next Lesson", "Previous Lesson", and sidebar curriculum drawer.
  - Auto-advance upon lesson video completion.
  - Explicit "Mark as Completed" button.
- **Split Workspace:**
  - Main video theater mode with responsive aspect ratio.
  - Multi-tab right-hand utility panel:
    - Tab 1: AI Study Notes & Key Takeaways.
    - Tab 2: Lesson Quiz & Comprehension Check.
    - Tab 3: Personal Timestamped Notes.

---

### Module 7: Smart Quiz Engine & "Replay the Moment"
- **Interactive MCQ Interface:**
  - Clean, distraction-free question cards with instant feedback upon submission.
  - Comprehensive answer explanation detailing *why* an answer is correct or incorrect.
- **"Replay the Moment" Video Seeking:**
  - For incorrect answers: an actionable "Replay the Moment" button appears alongside the explanation.
  - Clicking automatically jumps the embedded YouTube player to the exact timestamp where the instructor explained that concept, highlighting the video player.
- **Scoring & Retake Persistence:**
  - Calculates score percentage, updates user progress, logs attempt timestamp and score in database.
  - Unlimited retakes allowed with attempt history tracking.

---

### Module 8: Personal Timestamped Note-Taking
- **Real-Time Note Creation:**
  - User enters note text; system captures the current player playback position in seconds (e.g. `04:23`).
  - Formatted timestamp pill displayed beside note content.
- **Jump-to-Video Synchronization:**
  - Clicking any timestamp pill instantly seeks the YouTube player to that exact second.
- **CRUD Operations & Global Notes View:**
  - Edit note content, delete notes.
  - Dedicated "My Notes" section in user dashboard aggregating notes across all courses with direct course jump links.

---

### Module 9: Adaptive Daily Learning Planner
- **Target Setting:**
  - Daily study goal selector: 30 min, 60 min, 90 min, 120 min.
- **Dynamic Schedule Generator:**
  - Distributes enrolled course lessons across calendar days based on lesson duration + quiz time.
  - Updates automatically when lessons are completed or skipped via placement test.
- **Streak & Habit Tracker:**
  - Active study streak counter displaying fire badges and streak milestones.
  - Daily task checklist showing today's assigned lessons and completion status.

---

### Module 10: Community Course Discovery & Sharing
- **Public Course Catalog:**
  - Search by title, keyword, tag, or topic.
  - Filter by category (Programming, Business, Design, Science, Math, etc.), difficulty, and duration.
  - Sort by popularity (enrollment count), newest, or rating.
- **Zero-Quota Community Enrollment:**
  - Users can enroll in any existing public course instantly without spending personal generation quota.
- **Social Sharing:**
  - One-click copy link for public courses, social share buttons (Twitter/X, LinkedIn, WhatsApp).

---

### Module 11: Multi-Course Learning Roadmaps
- **Roadmap Creator & Studio:**
  - Title, description, target skill outcome, cover badge/icon.
  - Multi-stage curriculum organization (e.g., Phase 1: Fundamentals, Phase 2: Core Concepts, Phase 3: Advanced Projects).
  - Drag-and-drop or ordered reordering of courses within stages.
- **Community Roadmaps & Independent Enrollment:**
  - Public roadmap directory.
  - Independent user progress: enrolling in a roadmap tracks completion of constituent courses individually without interfering with creator or peers.

---

### Module 12: Subscriptions, Usage Governance & Sandbox Billing
- **Tier Architecture:**
  - Free ($0): 1 build/mo, max 6 hrs/course, community unlimited.
  - Pro ($19/mo or $190/yr): 5 builds/mo, max 10 hrs/course, 30 hrs total, priority build queue, retry capability.
  - Max ($49/mo or $490/yr): 20 builds/mo, max 20 hrs/course, 100 hrs total, top priority.
- **Quota Tracking & Enforcement:**
  - Real-time monthly usage meters on user dashboard and settings.
  - Hard guards blocking new course generation if video exceeds plan limits or monthly quota exhausted.
  - Sandbox payment checkout flow with realistic invoice generation and upgrade simulation.

---

### Module 13: Administrator Control Center & Telemetry
- **User Moderation:**
  - Search, filter, view details, change roles (USER, ADMIN), suspend/reactivate accounts.
- **Course & Content Moderation:**
  - Global course list, toggle visibility (PUBLIC, PRIVATE), delete flagged or broken courses.
- **AI Infrastructure Management:**
  - Configure active provider (Nemotron, OpenAI, Local Mock).
  - Set default models, temperature, max generation tokens.
  - Inspect generation queue, error logs, and execution duration.
- **System Telemetry & Analytics:**
  - Total users, active courses, total lessons generated, total learning hours consumed, generation success rate.
